<p>Some of the highlights of OCaml 5.4.0 are:</p>
<ul>
<li>Labelled tuples</li>
<li>Immutable arrays</li>
<li>Array literal syntax support for immutable arrays and <code>floatarray</code>s<br>
(through type-directed disambiguation)</li>
<li>Atomic record fields</li>
<li>Four new standard library modules: Pair, Pqueue, Repr, and Iarray</li>
<li>Restored "memory cleanup upon exit" mode</li>
<li>New chapter in the manual on profiling OCaml programs on Linux and macOS</li>
</ul>
<p>And a lot of incremental changes:</p>
<ul>
<li>Many runtime and code generation improvements</li>
<li>More than thirty new standard library functions</li>
<li>Nearly a dozen improved error messages</li>
<li>Around fifty bug fixes</li>
</ul>
