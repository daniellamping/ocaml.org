<p>CHANGES:</p>
<h3>Fixed</h3>
<ul>
<li>
<p>Fix the <code>menhir</code> opam dependency injection introduced in 3.23. Dune<br>
now only fills in the lower bound <code>{&gt;= "20180523"}</code> on an existing<br>
user-declared <code>menhir</code> dependency; it no longer adds <code>menhir</code> as a<br>
new dependency to packages that did not declare it themselves.<br>
(<a href="https://github.com/ocaml/dune/pull/14434" class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="4387547158" data-permission-text="Title is private" data-url="https://github.com/ocaml/dune/issues/14434" data-hovercard-type="pull_request" data-hovercard-url="/ocaml/dune/pull/14434/hovercard">#14434</a>, fixes <a href="https://github.com/ocaml/dune/issues/14428" class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="4384399653" data-permission-text="Title is private" data-url="https://github.com/ocaml/dune/issues/14428" data-hovercard-type="issue" data-hovercard-url="/ocaml/dune/issues/14428/hovercard">#14428</a>, <a href="https://github.com/robinbb" class="user-mention notranslate" data-hovercard-type="user" data-hovercard-url="/users/robinbb/hovercard" data-octo-click="hovercard-link-click" data-octo-dimensions="link_type:self">@robinbb</a>)</p>
</li>
<li>
<p>Gate the <code>dune</code> version-bound deduplication in generated opam files<br>
(introduced in 3.23) on <code>(lang dune 3.23)</code>. Projects at earlier lang<br>
versions get the prior <code>And [...]</code> shape — e.g.<br>
<code>{&gt;= "3.17" &amp; &gt;= "3.20"}</code> — restoring 3.22 behaviour and avoiding a<br>
silent change to opam output on dune-binary upgrade. (<a href="https://github.com/ocaml/dune/issues/14436" class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="4389438123" data-permission-text="Title is private" data-url="https://github.com/ocaml/dune/issues/14436" data-hovercard-type="issue" data-hovercard-url="/ocaml/dune/issues/14436/hovercard">#14436</a>,<br>
<a href="https://github.com/robinbb" class="user-mention notranslate" data-hovercard-type="user" data-hovercard-url="/users/robinbb/hovercard" data-octo-click="hovercard-link-click" data-octo-dimensions="link_type:self">@robinbb</a>)</p>
</li>
<li>
<p>Preserve library order when building a shared jsoo standalone runtime.<br>
(<a href="https://github.com/ocaml/dune/pull/14438" class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="4393228283" data-permission-text="Title is private" data-url="https://github.com/ocaml/dune/issues/14438" data-hovercard-type="pull_request" data-hovercard-url="/ocaml/dune/pull/14438/hovercard">#14438</a>, <a href="https://github.com/vouillon" class="user-mention notranslate" data-hovercard-type="user" data-hovercard-url="/users/vouillon/hovercard" data-octo-click="hovercard-link-click" data-octo-dimensions="link_type:self">@vouillon</a>)</p>
</li>
<li>
<p>Fix the fallback to the secondary compiler, allowing recovering of support for<br>
packages with upper bounds on OCaml less than 4.14. Packages depending on dune<br>
3.23.1 or later and with an upper bound on the OCaml compiler that is less<br>
than 4.14, will now be able to use the latest dune, but dune will be built<br>
with the secondary compiler at version 4.14. (<a href="https://github.com/ocaml/dune/pull/14443" class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="4394960825" data-permission-text="Title is private" data-url="https://github.com/ocaml/dune/issues/14443" data-hovercard-type="pull_request" data-hovercard-url="/ocaml/dune/pull/14443/hovercard">#14443</a>, <a href="https://github.com/Alizter" class="user-mention notranslate" data-hovercard-type="user" data-hovercard-url="/users/Alizter/hovercard" data-octo-click="hovercard-link-click" data-octo-dimensions="link_type:self">@Alizter</a>)</p>
</li>
<li>
<p>Fix the bootstrap on NetBSD by including <code>&lt;sys/wait.h&gt;</code> in <code>lev_stubs.c</code>,<br>
matching the existing FreeBSD/OpenBSD guard.<br>
(<a href="https://github.com/ocaml/dune/pull/14512" class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="4440053665" data-permission-text="Title is private" data-url="https://github.com/ocaml/dune/issues/14512" data-hovercard-type="pull_request" data-hovercard-url="/ocaml/dune/pull/14512/hovercard">#14512</a>, fixes <a href="https://github.com/ocaml/dune/issues/14484" class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="4415572063" data-permission-text="Title is private" data-url="https://github.com/ocaml/dune/issues/14484" data-hovercard-type="issue" data-hovercard-url="/ocaml/dune/issues/14484/hovercard">#14484</a>, <a href="https://github.com/0-wiz-0" class="user-mention notranslate" data-hovercard-type="user" data-hovercard-url="/users/0-wiz-0/hovercard" data-octo-click="hovercard-link-click" data-octo-dimensions="link_type:self">@0-wiz-0</a>)</p>
</li>
</ul>
