<p>CHANGES:</p>
<h2>Features</h2>
<ul>
<li>Add custom <a href="https://github.com/ocaml/ocaml-lsp/blob/ocaml-lsp-server/docs/ocamllsp/refactorExtract-spec.md"><code>ocamllsp/refactorExtract</code></a> request (<a href="https://github.com/ocaml/ocaml-lsp/pull/1545" class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="3236088197" data-permission-text="Title is private" data-url="https://github.com/ocaml/ocaml-lsp/issues/1545" data-hovercard-type="pull_request" data-hovercard-url="/ocaml/ocaml-lsp/pull/1545/hovercard">#1545</a>)</li>
<li>Add <code>destruct</code> custom request (<a href="https://github.com/ocaml/ocaml-lsp/pull/1583" class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="3833778556" data-permission-text="Title is private" data-url="https://github.com/ocaml/ocaml-lsp/issues/1583" data-hovercard-type="pull_request" data-hovercard-url="/ocaml/ocaml-lsp/pull/1583/hovercard">#1583</a>)</li>
<li>Add <code>locate_types</code> custom request (<a href="https://github.com/ocaml/ocaml-lsp/pull/1584" class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="3839296725" data-permission-text="Title is private" data-url="https://github.com/ocaml/ocaml-lsp/issues/1584" data-hovercard-type="pull_request" data-hovercard-url="/ocaml/ocaml-lsp/pull/1584/hovercard">#1584</a>)</li>
<li>Add support for the <code>textDocument/rangeFormatting</code> request (<a href="https://github.com/ocaml/ocaml-lsp/pull/1591" class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="4023954918" data-permission-text="Title is private" data-url="https://github.com/ocaml/ocaml-lsp/issues/1591" data-hovercard-type="pull_request" data-hovercard-url="/ocaml/ocaml-lsp/pull/1591/hovercard">#1591</a>)</li>
<li>Allow to configure merlin using build systems other than dune.<br>
If <code>$OCAMLLSP_PROJECT_BUILD_SYSTEM</code> environment variable is set then OCaml<br>
LSP will execute <code>$OCAMLLSP_PROJECT_BUILD_SYSTEM ocaml-merlin</code> command to get<br>
merlin configuration for a module. It is expected the command to communicate<br>
using <code>merlin-dot-protocol</code>.<br>
If <code>$OCAMLLSP_PROJECT_ROOT</code> environment variable is set then OCaml LSP will<br>
use it as a project root directory.</li>
</ul>
